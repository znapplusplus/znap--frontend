# Footer

Site footer with brand line and nav links.

## Import

```tsx
import { Footer } from "@/components/layout";
```

## Usage

```tsx
<Footer />
```

Takes no props.

## Do

- Update link targets here when public pages are added.

## Don't

- Don't hardcode the year — `new Date().getFullYear()` is intentional.
- Don't add page-specific content. The footer should be consistent across all public pages.
